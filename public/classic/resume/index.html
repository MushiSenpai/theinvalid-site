QLAB: Honest Quantum-ML Lab → github.com/MushiSenpai/qlab · case study

A feasibility lab with one rule: a quantum number is never shown without its classical baseline. Eleven experiments, two runs on real quantum hardware (IBM superconducting, IonQ trapped-ion), zero manufactured wins.

  • Reproduced a published quantum advantage (0.900 vs a weak classical 0.730), then erased it three ways: a fairly tuned classical model (0.910), classical dequantization (0.900), and device noise
  • Measured a barren plateau collapsing gradient variance 1,436×, and hit the 32GB statevector wall at 30 qubits. The deliverable is judgment a buyer can trust, not hype

OPEN-SOURCE CONTRIBUTIONS — 5 merged

Upstream fixes submitted to the tools I run in production — each links to the live PR.

  • FlagEmbedding (BGE-M3 / bge-reranker-v2-m3) — #1584: device= was silently swallowed by **kwargs, loading the reranker across every visible GPU (OOM); aliased it to devices= with a regression test.
  • qdrant-client — #1247 (merged): local mode runs exact search, so search_params is ignored — but silently, making exact=True look like a no-op. Added a one-time warning + batch-path coverage + regression tests.
  • whisperX — #1442: a chunk mis-detected as a language with no alignment model crashed the entire transcription; made it warn and keep the segment-level result. Validated on real audio with a same-clip before/after.
  • ComfyUI-WanVideoWrapper — #2041: the VRAM-management node wrapped meta-device tensors before materializing them → Cannot copy out of meta tensor crash on no-LoRA VACE; materialize-before-wrap fix, validated end-to-end on a Wan-VACE run (live before/after traceback).
  • MuseTalk — #419, #420: a PyTorch 2.6 weights_only crash on the legacy face-parse checkpoints; an UnboundLocalError on image input — two clean, low-risk fixes.
  • fish-speech — #1303, #1304: empty TTS text returned an HTTP 500 (which streaming clients wrote as a .wav); constrained the request schema to reject it with a clean 4xx (Fixes #946); pyaudio’s hard PortAudio build dependency broke every headless / slim / API-only install; moved it to an optional [client] extra.
  • colpali (vision-document retrieval) — #418 (merged): wired fast-plaid in as the plaid optional dependency — the maintainer-requested integration (#335) that a previous volunteer had left stalled.
  • YuE (music generation) — #153 (merged): the documented git clone of the codec checkpoints silently yields ~133-byte LFS pointer stubs when git-lfs is missing or the HF bandwidth quota is hit; added an hf download fallback + a stub warning (#118).
  • PyDriller (git repository mining) — #326 (merged): on a shallow clone (--depth 1, the actions/checkout default) the missing parent made modified_files die with a bare exit code(128) naming neither the cause nor the fix; it now warns on open and raises an actionable ShallowRepositoryError, with a depth-1 regression test (Fixes #229, open since 2022).
  • trimesh (3D mesh processing) — #2605 (merged): simplify_quadric_decimation(percent=) is forwarded as target_reduction, so it is the fraction of faces REMOVED, not kept, and the docstring stopped mid-sentence — the inversion silently returned 8 triangles for a 1200-face target in my 3D pipeline; completed the description with measured numbers (0.9 keeps 510 of 5120 faces).
  • xFormers (attention kernels) — #1411: the README’s development-binaries install omits the --index-url the stable block treats as essential, so pip install --pre -U xformers resolves from PyPI and can install a wheel built for a different CUDA version over a cuda-specific or nightly PyTorch — on Blackwell that surfaced as an NCCL ABI crash at import, not an install error; documented the failure mode and the matching nightly-index form.
